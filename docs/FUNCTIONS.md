# مرسال — جرد الوظائف ومقارنة «قبل/بعد»

هذا المستند يوثّق وظائف التطبيق كما استُخرجت من:
- **الأصل**: `bulk-sender.apk` الإصدار 3.3.5 (versionCode 14، الحزمة `com.whatsappbot.bulk`) — فُكّ بأداة `jadx`.
- **الكود المصدري**: مستودع المالك الخاص، الإصدار 3.3.3 (versionCode 11).
- **الجديد**: «مرسال» 1.0.0 (الحزمة `cloud.lork.mursal`) المبني في هذا المستودع.

---

## 1) نظرة عامة

«مرسال» أداة إرسال رسائل متعددة داخل محادثة واتساب مفتوحة، تعمل عبر **خدمة إمكانية الوصول** (Accessibility) و**أيقونة عائمة** فوق التطبيقات. المستخدم يفتح المحادثة بنفسه، ويلصق الرسائل في لوحة صغيرة، ويضبط المعدّل، ثم يبدأ الإرسال. المعالجة كلها محلية على الجهاز.

## 2) قائمة الوظائف الكاملة

### الشاشات والمكوّنات
| المكوّن | الوصف |
|---|---|
| `QuickBubbleActivity` | **نقطة الدخول الوحيدة** (الأيقونة المنبثقة). عند فتح التطبيق: يفحص الأذونات؛ إن توفّرت يشغّل الأيقونة العائمة ويعود للخلفية فورًا؛ وإلا يفتح شاشة الإعداد لمنح الإذن الناقص. شاشة شفافة. |
| `HomeActivity` | شاشة الإعداد/التحكم. تُفتح عند نقص إذن، أو من الإشعار، أو من الاختصار. تعرض حالة الأذونات وأزرار: تفعيل إمكانية الوصول، السماح بالعرض فوق التطبيقات، تفعيل الإرسال، إضافة اختصار، التحقق من التحديثات. |
| `BulkAccessibilityService` | محرّك الإدخال والإرسال داخل واتساب عبر عقد إمكانية الوصول. |
| `FloatingBubbleService` | الأيقونة العائمة + لوحة الإرسال (خدمة أمامية foreground). |
| `FileProvider` | لمشاركة ملف تحديث APK عند التثبيت. |

### آلية الإرسال (المحرّك — دون أي تغيير)
- البحث عن نافذة محادثة واتساب عبر كل النوافذ التفاعلية (`WhatsAppWindows`)، لدعم واتساب العادي، واتساب للأعمال `w4b`، والنسخ المزدوجة على سامسونج/شاومي.
- تحديد حقل الإدخال وزر الإرسال عبر معرّفات العرض (`WhatsAppNodes`): `id/entry`, `id/conversation_entry`, `id/send`, `id/send_container`… مع احتياطيات بالنص/الوصف ("send"، "إرسال"…).
- الإدخال عبر `ACTION_SET_TEXT` ثم الضغط عبر `ACTION_CLICK`.
- تقسيم النص إلى رسائل: فقرات (سطر فارغ) أو أسطر (`MessageParser`).
- التحكم بالمعدّل: 1…1000 رسالة/دقيقة (أزرار سريعة 10/60/300/1000 + شريط تمرير)، بحساب تأخير `60000/mpm`.
- حالات الجلسة: جاهز / بانتظار المحادثة / جارٍ الإرسال (عدّاد sent/total) / اكتمل / متوقف (`BulkSession`).
- فقاعة قابلة للسحب، وإفلاتها في منطقة سفلية ينهي الجلسة.
- دعم الأجهزة ذات التطبيقات المزدوجة بإرشادات مخصّصة (`DualAppSupport`).

### الأذونات
`INTERNET`, `ACCESS_NETWORK_STATE`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE`, `POST_NOTIFICATIONS`, `WAKE_LOCK`, `SYSTEM_ALERT_WINDOW`, `REQUEST_INSTALL_PACKAGES`.

### تأكيدات من فحص الـAPK الناتج
- الأذونات مطابقة للأصل (عدا إذن AndroidX المُولّد تلقائيًا والمُسمّى باسم الحزمة).
- لا وجود لأي من: `erp.lork.cloud`، `bot.lork.cloud`، `/api/license/*`، `LicenseClient`، `LicensePrefs` داخل الـAPK.
- رابط التحديث الوحيد = `raw.githubusercontent.com/loorksy/Wh-sender-/.../app-update.json`.
- المُشغِّل = `QuickBubbleActivity`؛ لا توجد `ActivationActivity`.
