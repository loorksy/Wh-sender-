# مرسال (Mursal)

تطبيق أندرويد **مستقل** لإرسال رسائل متعددة داخل محادثة واتساب مفتوحة، عبر خدمة إمكانية الوصول وأيقونة عائمة. يعمل **بدون أي مفتاح ترخيص** وبدون اتصال بأي خادم تفعيل، ومنفصل تمامًا عن التطبيقات الأخرى (اسم حزمة ومفتاح توقيع خاصّان به).

> **مهم:** المعالجة محلية على الجهاز. أنت تفتح المحادثة بنفسك داخل واتساب، وتلصق الرسائل، ثم تبدأ الإرسال. استخدم الأداة بما يتوافق مع شروط واتساب والأنظمة المعمول بها؛ الإرسال الجماعي غير المرغوب قد يعرّض رقمك للحظر.

---

## الوظائف
- إرسال عدّة رسائل تِباعًا داخل محادثة واتساب / واتساب للأعمال / واتساب المزدوج (سامسونج، شاومي/ريدمي).
- **أيقونة عائمة** قابلة للسحب تفتح لوحة إرسال صغيرة؛ وإفلاتها أسفل الشاشة ينهي الجلسة.
- لصق الرسائل (زر «لصق») واختيار طريقة التقسيم من مفتاح «فقرات | أسطر» (فقرات مفصولة بسطر فارغ، أو كل سطر رسالة مستقلة)، مع عدّاد مباشر للرسائل.
- ضبط **معدّل الإرسال** من 1 إلى 1000 رسالة/دقيقة (أزرار سريعة 10/60/300/1000 + شريط تمرير لوغاريتمي)، الافتراضي **300 رسالة/دقيقة**، ويُحفظ آخر معدّل تختاره على الهاتف حتى بعد إنهاء الجلسة أو إعادة التشغيل.
- حالة الإرسال تظهر على زر الإرسال أثناء العمل (مُرسَل/الإجمالي)، وشاشة نجاح عند الانتهاء (عدد الرسائل والمعدّل) مع «بدء إرسال جديد»، وإشعار خدمة أمامية.
- شاشة إعداد لمنح إذنَي **إمكانية الوصول** و**العرض فوق التطبيقات**، وإضافة اختصار للشاشة الرئيسية.
- **الفتح على الأيقونة المنبثقة فقط**: الضغط على أيقونة التطبيق يشغّل الأيقونة العائمة مباشرة.
- واجهة عربية RTL هادئة تتبع **الوضع الفاتح/الداكن** للهاتف، بخط IBM Plex Sans Arabic (مرخّص بـSIL OFL، النص في [`licenses/`](licenses/)).
- تحقّق **اختياري** من التحديثات من هذا المستودع (غير إجباري إطلاقًا).

تفاصيل كاملة وجرد الوظائف ومقارنة «قبل/بعد» في [`docs/FUNCTIONS.md`](docs/FUNCTIONS.md).

## إزالة الترخيص
أُزيل نظام الترخيص بالكامل مقارنةً بالنسخة الأصلية (3.3.5):
- لا شاشة تفعيل، ولا رمز ترخيص.
- لا اتصال بخادم الترخيص (`erp.lork.cloud` / `/api/license/*`).
- لا توقّف عند تعطيل الترخيص أو عند تعذّر الوصول للخادم.
- **التحديث الإجباري معطَّل**؛ التحقق من التحديثات صار اختياريًا وموجَّهًا إلى إصدارات هذا المستودع فقط، فلا يُستبدَل التطبيق بالنسخة المرخّصة.

## المتطلبات
- أندرويد 7.0 (API 24) فأعلى.
- JDK 17 فأعلى، وAndroid SDK (platform android-34، build-tools 34).

## البناء
```bash
# 1) حدّد مسار Android SDK
echo "sdk.dir=/path/to/Android/sdk" > local.properties

# 2) بناء نسخة تجريبية (لا تحتاج مفتاح توقيع)
./gradlew :app:assembleDebug
#   الناتج: app/build/outputs/apk/debug/app-debug.apk

# 3) بناء نسخة Release موقّعة
#    انسخ النموذج واملأ بيانات مفتاحك:
cp keystore.properties.sample keystore.properties
#    ثم ابنِ:
./gradlew :app:assembleRelease
#   الناتج: app/build/outputs/apk/release/app-release.apk
```
إن لم يوجد `keystore.properties` ولا متغيّرات البيئة، تُبنى نسخة Release **غير موقّعة** (يظل المشروع قابلًا للبناء للجميع).

يمكن أيضًا تمرير بيانات التوقيع عبر متغيّرات البيئة بدل الملف:
`MURSAL_STORE_FILE`, `MURSAL_STORE_PASSWORD`, `MURSAL_KEY_ALIAS`, `MURSAL_KEY_PASSWORD`.

## التثبيت
- حمّل أحدث APK من مجلد [`releases/`](releases/) إلى هاتفك وثبّته (قد يلزم السماح بـ«التثبيت من مصدر غير معروف»).
- بعد التثبيت، افتح التطبيق مرة لمنح إذنَي **إمكانية الوصول** و**العرض فوق التطبيقات** من شاشة الإعداد.
- بعدها يكفي الضغط على أيقونة التطبيق لتشغيل الأيقونة العائمة.
- يُثبَّت بجانب أي نسخة أخرى لاختلاف اسم الحزمة (`cloud.lork.mursal`).

## التوقيع والتحديثات
- التطبيق موقّع بمفتاح Release **جديد** خاص بـ«مرسال».
- ملف المفتاح (`*.jks`) و`keystore.properties` **غير مرفوعين** إلى المستودع (راجع `.gitignore`).
- **تنبيه:** يجب الاحتفاظ بملف المفتاح وكلمات مروره في مكان آمن. فقدانه يمنع إصدار تحديثات تُثبَّت فوق النسخة الحالية (سيتطلب الأمر إلغاء التثبيت وإعادة التثبيت بنسخة موقّعة بمفتاح جديد).
- لإصدار تحديث: ارفع APK الجديد إلى `releases/` وحدّث `releases/app-update.json` (ارفع `versionCode`). يفحص التطبيق هذا الملف، ويعرض التحديث كـ«اختياري» فقط.
